## 🔧 Como Executar o Projeto Localmente

Caso queira clonar e rodar o projeto na sua máquina:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Feppeli/my_website.git
   ```

2. **Navegue até o diretório do projeto:**
   ```bash
   cd my_website
   ```

3. **Abra o projeto:**
   - Se for um site estático (HTML/CSS/JS puro), basta abrir o arquivo `index.html` no seu navegador ou usar a extensão *Live Server* do VS Code.
   - Se utilizar um framework (Node.js/React/Vue), instale as dependências e rode o servidor de desenvolvimento:
     ```bash
     npm install
     npm run dev
     ```
